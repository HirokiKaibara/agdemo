Legacy VBA Refactoring Navigator

複雑な Excel / Access VBA を
現状把握からリファクタリング設計までつなぐ

アップロードしたVBAコードから、現状仕様書・問題点分析・詳細リファクタリング案・設計書を順番に出力し、 「何をどう直すか」を迷いにくくするデモです。

解析対象コード

解析は常に Gemini API を使用します。ファイルを再選択すると既存一覧へ追加され、同名ファイルは差し替えます。複数選択時は上部のファイル名クリックで表示を切り替えられます。

入力: コード貼り付けモード

ファイル未選択

読む導線

  1. 現状仕様書で、対象機能・テーブル・依存関係を把握する
  2. 問題点分析で、障害化しやすい箇所と優先順位を確認する
  3. 詳細リファクタリング案で、採るべき代替案と実施順を決める
  4. 設計書で、分離後の責務と移行フローを確認する

実行ステータス

ファイル読込またはコード貼り付け後に解析できます。

解析サマリー

0 対象ファイル
0 主要問題点
0 候補テーブル
0 リファクタリング段階

Step 1

現状仕様書

現行の機能、フロー、依存テーブル、主要手続きを把握するための資料です。

ここに現状仕様書が表示されます。

Step 2

問題点分析

副作用、責務の混在、SQL組立、エラー制御など、改修優先度を見極めるための分析です。

ここに問題点分析が表示されます。

Step 3

詳細リファクタリング案

代替案、候補バージョン、段階的ロードマップ、実施時のガードレールをまとめます。

ここに詳細リファクタリング案が表示されます。

Step 4

リファクタリング設計書

目標アーキテクチャ、モジュール責務、移行フロー、将来設計上のリスクを整理します。

ここにリファクタリング設計書が表示されます。
